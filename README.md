# E7sbly — احسبلى

تطبيق أندرويد عربى يقارن القيمة الفعلية للمنتجات: أدخل وزن وسعر منتجين حتى خمسة منتجات، وسيحسب سعر الكيلو ويرتبهم من الأرخص إلى الأغلى. يمكن استخدام الجرام والكيلوجرام معًا. كل الأسعار فى المقارنة الواحدة يجب أن تكون بنفس العملة.

الإصدار الحالى **2**، باسم الحزمة `com.ehsably.app`، ويدعم **Android 10 أو أحدث**. يظهر اسم التطبيق على الموبايل **E7sbly**. يمكنك الضغط على أيقونة الكرة الأرضية المتحركة أعلى الشاشة لاختيار العربية أو English من نافذة اللغات؛ يُحفظ الاختيار وتتبعه اتجاهات الواجهة والأرقام والنتائج والتنبيهات، مع الاحتفاظ ببيانات المنتجات والوزن المطلوب. العربية هى اللغة الافتراضية، وخط Montserrat Arabic والألوان `#1f347d` و`#3c89bd` مشتركة بين اللغتين. ملف `translations.json` مشترك بين Android ومعاينة الويب.

## تشغيل المعاينة والاختبارات

المعاينة مستقلة عن شاشة Android الأصلية، وتعمل باستخدام Node.js دون مكتبات إضافية:

```sh
npm start
```

افتح [معاينة الموبايل المحلية](http://127.0.0.1:4173/preview). يحتفظ كل عرض ببياناته محليًا.

```sh
npm test
```

واختبارات Java باستخدام JDK 17 على Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\native-calculator\run-tests.ps1
```

تضم الاختبارات 20 اختبار JavaScript و18 اختبار Java. تشمل المقارنة الدقيقة، الأوزان المختلفة، عدد العبوات، وتكلفة تغطية الوزن المطلوب، واكتمال ترجمة النصوص واسم التطبيق وحد Android الأدنى.

## تثبيت النسخة التجريبية

حمّل [ملف APK للإصدار 2](public/E7sbly-Final.apk) وانقله إلى هاتف Android 10 أو أحدث، ثم افتحه واختر «تحديث» إذا كانت النسخة السابقة موجودة، أو «تثبيت» عند أول استخدام. اسمح بالتثبيت من التطبيق الذى فتحت الملف منه عند ظهور طلب أندرويد. لا يلزم حذف النسخة القديمة؛ الملف المرفق يستخدم اسم الحزمة ومفتاح التوقيع نفسيهما. هذه نسخة تجريبية موقعة بمفتاح تطوير؛ لم تُنشر على Google Play.

التطبيق يعمل بدون إنترنت، دون حساب أو إعلانات أو أذونات حساسة. البيانات التى تُحفظ تبقى محليًا على الجهاز؛ حذف بيانات التطبيق أو إزالته يمسحها. شاشة الحساب الافتراضية فى الإصدار 1.4.0 تستخدم عناصر Android مباشرة، ولا تحتاج إلى Android System WebView عند التشغيل. خط Montserrat Arabic المرفق داخل الحزمة، والألوان الأساسية `#1f347d` و`#3c89bd`.

تحتفظ الواجهة الأصلية ببياناتها السابقة، لكن شاشة Android لها حفظ مستقل؛ قد تحتاج لإدخال منتجاتك مرة أخرى بعد الانتقال إليها.

## مثال الحساب

فى الإصدار 2، يظهر «محتاج وزن محدد؟» كعنوان واضح فوق أول منتج، وتحته خانة وزن اختيارية دائمة الظهور. أدخل الوزن المطلوب بالجرام أو الكيلو لتتحول المقارنة إلى أقل مبلغ يُدفع لشراء عبوات كاملة تغطّى احتياجك. يعرض كل اختيار عدد العبوات، إجمالى الوزن، والزيادة عن المطلوب. تتم مقارنة كل منتج على حدة؛ لا يتم خلط منتجات مختلفة. عند تساوى التكلفة تتساوى المرتبة ويظهر الوزن الزيادة الأقل أولًا. ترك خانة الوزن فارغة يعيد المقارنة بسعر الكيلو، ومسح كل القيم يمسحها أيضًا. قيم الوزن غير المفعّلة فى الإصدارات السابقة لا تُفعّل تلقائيًا عند التحديث.

مثال: لاحتياج كيلو واحد، عبوة ٣٢٠ جرام بـ٢٥ تحتاج ٤ عبوات بـ١٠٠ ووزن ١٢٨٠ جرام، بينما عبوة كيلو بـ٨٠ تغطّى الاحتياج بتكلفة أقل بـ٢٠. عدد العبوات اليدوى فى المقارنة العادية مستقل عن العدد المحسوب تلقائيًا للاحتياج.

عند المقارنة العادية، يظهر اسم الأوفر وفرق السعر بالجنيه مقارنة بأغلى منتج لنفس الوزن، مع توضيح أساس المقارنة على كيلو واحد ونسبة التوفير. فرق السعر يُحسب قبل التقريب؛ سعر العبوة وحده لا يكفى للمقارنة بين الأوزان المختلفة. عند تفعيل الوزن المطلوب، يعتمد الترتيب والتوفير على إجمالى تكلفة العبوات الكاملة.

أيقونات Android تُرسم فعليًا عبر PathMeasure وتوقيت إطارات مستقل عن معامل سرعة ValueAnimator لدى النظام: ثانيتان للرسم وثانيتان للمحو، تتكرران باستمرار دون فواصل، وتبدأ بعد ظهور النافذة. تتوقف الحركة عند فقدان تركيز النافذة أو إزالة العنصر، وتعود عند ظهورها. تظل حركات ظهور الشاشة متوافقة مع إعداد حركة النظام. المعاينة تستخدم SVG stroke-dashoffset وتحترم تقليل الحركة فى المتصفح. نافذة المطور تضم الصورة كاملة بجوار الاسم، والنبذة داخل الإطار، ورابطًا تحته خط مع أيقونة كرة أرضية متحركة.

منتج ٣٠٠ جرام بسعر ٣٠، ومنتج ٤٥٠ جرام بسعر ٤٠:

- الأول: ١٠٠ لكل كيلو.
- الثانى: حوالى ٨٨٫٨٩ لكل كيلو، وبالتالى هو الأوفر رغم أن سعر العبوة أعلى.

الترتيب يعتمد على السعر لكل وحدة موحدة، وليس على سعر العبوة. النسبة الموضحة للتوفير تقارن تكلفة الكمية نفسها.

## ملفات المشروع

- `app/src/main/assets/`: واجهة المعاينة، الحسابات JavaScript، وملفات الخط المحلية.
- `app/src/main/java/com/ehsably/app/MainActivity.java`: نقطة تشغيل Android.
- `app/src/main/java/com/ehsably/app/NativeComparisonView.java`: شاشة الحساب باستخدام عناصر Android والحفظ المحلى.
- `app/src/main/java/com/ehsably/app/NativeCalculator.java`: حسابات المقارنة الدقيقة باستخدام BigDecimal.
- `app/src/main/res/`: اسم التطبيق وألوانه وأيقونته.
- `tests/`: اختبارات منطق المقارنة.

شاشة Android الجديدة لا تنشئ WebView. ملفات HTML وCSS وJavaScript باقية لمعاينة التصميم وتشغيل النسخة المحلية بالمتصفح أثناء التطوير، وبيانات المعاينة مستقلة عن حفظ شاشة Android.

الشاشة الرئيسية فى الإصدار 2 تستخدم مسافات وبطاقات مدمجة تتكيّف مع ارتفاع الشاشة. تظهر خانة الوزن المطلوب والمنتجان وزر الحساب معًا، ويظل زر الحساب ثابتًا أسفل الشاشة. تمت مراجعة المعاينة عند 320×568 بالعربية والإنجليزية وعند 360×640 دون تمرير، مع ظهور الإضافة ومسح القيم أيضًا. شاشة Android تستخدم بطاقات أقصر ونصوصًا توضيحية أقل على الشاشات القصيرة، مع بقاء التسميات والمدخلات الأساسية واضحة. يمكن التمرير عند إضافة منتجات أخرى أو فتح لوحة المفاتيح. يظل رقم النسخة الظاهر 2 مع زيادة كود التحديث الداخلى.

## إعادة البناء على Windows

يتضمن المشروع سكريبتًا مباشرًا يستعمل أدوات Android الرسمية دون Android Studio أو Gradle:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-android.ps1
```

يبحث السكريبت عن OpenJDK 17 وأدوات Google Build-Tools 35.0.0 ومنصة Android 35 داخل `.tools/`، ثم يجمع الموارد وJava وDEX، ويحاذى APK ويوقعه ويتحقق من التوقيع. يمكن تحديد الأدوات يدويًا:

```powershell
.\build-android.ps1 -JavaDirectory 'C:\jdk-17' -BuildToolsDirectory 'C:\Android\Sdk\build-tools\35.0.0' -AndroidJar 'C:\Android\Sdk\platforms\android-35\android.jar'
```

أدوات `.tools/` خارج Git، ولا تُوزّع مع التطبيق. يمكن تنزيلها من [أدوات Google Android الرسمية](https://developer.android.com/studio) و[Microsoft OpenJDK](https://learn.microsoft.com/java/openjdk/download). راجع تراخيص مزوديها عند إعادة توزيع الأدوات.

مفتاح التوقيع المحلى `.tools/ehsably-debug.keystore` غير مرفوع إلى الريبو. احتفظ به فى نسخة احتياطية آمنة لإنتاج تحديثات تقبل التثبيت فوق التطبيق الحالى. البناء على جهاز جديد بدون المفتاح نفسه يُنتج توقيعًا مختلفًا. سجل Git يتضمن الكود والأصول والاختبارات وآخر APK، ويستثنى أدوات SDK وJDK ومخرجات البناء والسجلات والنسخ القديمة.

للتطوير باستخدام Android Studio، افتح مجلد المشروع وثبت SDK 35، أو استعمل JDK 17 مع Gradle Wrapper:

```powershell
.\gradlew.bat assembleDebug
```

ملفات Gradle مهيأة للإصدار 8.9 وAndroid Gradle Plugin 8.7.3. أول تشغيل Gradle يحتاج تنزيل اعتماداته. مخرجاته فى `app/build/outputs/apk/debug/`.

## النشر مستقبلًا

قبل النشر، يلزم اختيار هوية الحزمة النهائية وتوقيع إصدار بمفتاح خاص آمن، وتجربة التطبيق على أجهزة فعلية، وتجهيز بيانات وسياسات متجر Google Play. لا تستخدم مفتاح التطوير المضمن فى مجلد الأدوات لتوقيع إصدار منشور.

رابط «مسح كل القيم» تحت إضافة منتج يمسح الأسماء والأوزان والأسعار، ويعيد منتجين فارغين مرقمين. حقل الاسم يوضح أنه اختيارى.

فى نتائج المقارنة العادية، زرا + و− يغيران عدد العبوات من 1 إلى 99 ويعرضان إجمالى الوزن والسعر، مع بقاء الترتيب حسب قيمة نفس الوزن. يتضمن الحفظ عدد العبوات ويعيده المسح إلى 1. بعد الحساب، يظهر «تعديل المنتجات» فى المعاينة، ويختفى زر الحساب خلف نافذة النتائج الأصلية حتى إغلاقها. تتحرك الأيقونات والسهم وأرقام النتائج باستمرار أثناء ظهور الشاشة.

نافذة المطور تعرض المحتوى كاملًا بدون تمرير، وتضبط حجمه على ارتفاع الشاشة المتاح بدل فرض ارتفاع أصغر من محتواها. يظل زر الإغلاق والرابط ظاهرين، وتظهر العناصر بالتتابع. الاسم والمسمّى باللبنى أعلى الإطار، والوصف الرمادى بخط Medium أكبر بجوار الصورة الكاملة. رابط الموقع تحته خط وأيقونة متحركة. يحتفظ المشروع بالصورة والخطوط والأيقونة داخل أصول التطبيق للعمل بدون إنترنت. يظهر رقم النسخة «2» فى التطبيق وإعدادات Android.
